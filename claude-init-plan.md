# Claude Code Initialization Plan

## Objective
Initialize Claude Code for the Go + Next.js full-stack project with memory and token optimization, then commit and push all non-local configuration files.

## Context
- **Project**: Go (Gin) backend + Next.js 16 frontend monorepo
- **Size**: ~930 MB total, but ~870 MB is excludable (node_modules, build artifacts)
- **Architecture**: Clean Architecture (backend), React App Router (frontend)
- **Current State**: Minimal Claude config exists in `.claude/settings.local.json`

### 2. Create CLAUDE.md Documentation
**Path**: `/CLAUDE.md`

Comprehensive developer context for Claude Code:

**Structure**:
1. **Project Overview**
   - Full-stack starter kit with Go backend + Next.js frontend
   - JWT + RBAC authentication system
   - Clean Architecture pattern

2. **Architecture**
   - Backend: `Handler → Service → Repository → Model`
   - Frontend: App Router with client/server components
   - API: REST with auto-refresh token mechanism

3. **Directory Structure**
   - Backend: `cmd/`, `internal/{handler,service,repository,model}`, `pkg/`, `migrations/`
   - Frontend: `app/`, `components/`, `lib/`, `types/`
   - Root: `scripts/`, `Makefile`, `docker-compose.yml`

4. **Tech Stack**
   - **Backend**: Go 1.21+, Gin, GORM, PostgreSQL, JWT, Swaggo
   - **Frontend**: Next.js 16, React 19, TypeScript, Tailwind CSS, React Query
   - **Infra**: Docker Compose, Make, Air (live reload)

5. **Development Workflow**
   - Start all: `make start` (DB → Backend → Frontend)
   - Stop all: `make stop`
   - Status: `make status`
   - Logs: `make logs`

6. **Common Tasks**
   - Migrations: `make migrate-create`, `make migrate-up`, `make migrate-down`
   - Backend dev: `cd backend && air`
   - Frontend dev: `cd frontend && npm run dev`
   - Database: `make dev-db`

7. **Key Implementation Notes**
   - **Backend Docs**: `backend/docs/` is auto-generated by swaggo - never edit manually
   - **JWT Refresh**: Frontend auto-refreshes tokens on 401 responses
   - **RBAC**: Admin endpoints require admin role via middleware
   - **CSV**: Import/export implemented for user management

8. **API Endpoints**
   - Frontend: `http://localhost:3000`
   - Backend: `http://localhost:8080`
   - Swagger: `http://localhost:8080/swagger/index.html`
   - Health: `http://localhost:8080/health`

9. **Critical Files**
   - Backend entry: `backend/cmd/api/main.go`
   - Backend config: `backend/internal/config/config.go`
   - Frontend layout: `frontend/app/layout.tsx`
   - API client: `frontend/lib/api/client.ts`
   - Auth middleware: `backend/internal/middleware/auth.go`
